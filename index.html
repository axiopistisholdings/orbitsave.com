What it does

Landed-cost lookupItem, live shipping, duty and tax — per product, per quantity, for the US and Canada.
Supplier matchThe candidate suppliers behind a product, with variant/SKU and a ready-to-use order spec.
Built for agentsA REST API and an MCP server — software and AI agents use the same engine as the site.
Honest by design. Every quote shows the rate date, the exchange rate used and a confidence level — estimates with an accuracy promise, never a customs ruling. Over 25% duty overshoot gets credited; unavailable freight shows no total rather than a wrong one.
